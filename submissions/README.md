# submissions/ — candidate raw replies

One file per candidate run, named after the model exactly as it should appear on the leaderboard:

```text
submissions/gpt-5.2.md
submissions/claude-opus-4-6.md
submissions/gemini-3-pro.md
```

- The contents are **verbatim** — paste the full unedited model reply to `test.md`.
- Nothing is committed by default (see `.gitignore`); commit a submission file when you open the PR for its leaderboard entry.

How to run a model: see step 1 of [`docs/methodology.md`](../docs/methodology.md) — or just grab [`test.md`](../test.md).
